🆕 Updates

Complete development history of Roblox Society

Period Update Details
Mid-Summer 2022 🎉 Initial Release Bot launched with 2 commands: /rs (asset/marketplace) and /user info (user information)
Late 2022 - 2023 ⚙️ Development Phase Multiple bot recreations and layout changes. Experimental development period with limited feature expansion.
2023/2024 🏢 Kurrasch Systems Acquisition Kurrasch Network acquired and became Kurrasch Systems. Marked turning point for bot development.
Early 2024 🚀 Major Development Begins Started aggressive bot recreation and advancement initiative. Systematic expansion of features began.
2024 - Phase 1 👕 Marketplace Expansion Added: /rsgroup, /asset content, /asset render, /bundle_info, /img2model
2024 - Phase 2 🧑‍🦲 Users Expansion Added: /disc2rbx, /user has_badge, /user outfits suite, /user avatar commands
2024 - Phase 3 🎮 Games v3 Launch Introduced: /game badge image, /game badge checklist
2024 - Phase 4 🪖 Groups Category Added: /group info, /group members, /group icon
2024 - Phase 5 📤 Role Collector Launched innovative role collection game system with rarity mechanics, booster exclusives, and server configuration
2024 - Phase 6 📈 Economy System Deployed: /devex, /limited cheapest, /limited search for Robux/USD conversion and limited items
2024 - Phase 7 ⁉️ Miscellaneous Added utility commands and tools
2024 - Phase 8 🏛️ Community Features Established Q&A section and Hall of Fame for community engagement
Ongoing 🔧 Active Development Continuous bug fixes, disabled command repairs, and new feature exploration

Note: Some commands are temporarily disabled while undergoing fixes and improvements. These will be restored in future updates with enhanced functionality.

📤 Role Collector

Role Collector is server game where server members can collect rare roles based off their rarity!

Contact Dev if you find any vulns. I'll try to make it worth your time with exclusive features that dont exist yet :0

Things to know in general

-> Roles that were deleted from the server and previously part of Role Unboxer will be automatically removed from the database.

-> Roles aren't pinged.

-> There's no unboxable role limit atm.

/role_collector_configure settings

Server admins can configure Role Collector settings with this command.

You can run the command without any options to see the current configuration on file.

Options | (r)equired - (o)ptional

Information

enabled (o) Can members collect roles? [?]
cooldown (o) The cooldown for collecting roles. [?]
booster_cooldown (o) The booster cooldown for collecting roles. [?]
unbox_amount How many roles will the member unbox at once? [?]
booster_unbox_amount How many roles will the server boosting member unbox at once? [?]
separator Give a specific role to the member when they collect a role. [?]
remove_self_unboxed_roles Can members remove roles they've unboxed from themselves?
remove Remove the separator, configuration, server cooldowns, or everything. [?]

/role_collector_configure role

Configure a role for Role Collector

Roles above Roblox Society's highest role cannot be an unboxable role.

Server admins cannot make roles that're higher than there own unboxable. [?]

/role_collector unbox

Unbox a role in the server.

simulate Tests the command a specified number of times to get an idea of the current role probabilities

/unboxable_roles

View all of the unboxable roles in a server.

Hide_special_roles Hides both 'server booster only' and 'unobtainable' roles so you'll only see roles you can obtain through /unbox_role

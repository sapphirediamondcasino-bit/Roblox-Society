📤 Role Collector

Role Collector is server game where server members can collect rare roles based off their rarity!

Contact Dev if you find any vulns. I'll try to make it worth your time with exclusive features that dont exist yet :0

Things to know in general

-> Roles that were deleted from the server and previously part of Role Unboxer will be automatically removed from the database.

-> Roles aren't pinged.

-> There's no unboxable role limit atm.

/role_collector_configure settings ✅ Active

Server admins can configure Role Collector settings with this command.

You can run the command without any options to see the current configuration on file.

Options | (r)equired - (o)ptional

enabled (o) Can members collect roles? [?]
cooldown (o) The cooldown for collecting roles. [?]
booster_cooldown (o) The booster cooldown for collecting roles. [?]
unbox_amount How many roles will the member unbox at once? [?]
booster_unbox_amount How many roles will the server boosting member unbox at once? [?]
separator Give a specific role to the member when they collect a role. [?]
remove_self_unboxed_roles Can members remove roles they've unboxed from themselves?
remove Remove the separator, configuration, server cooldowns, or everything. [?]

/role_collector_configure role ✅ Active

Configure a role for Role Collector

Roles above Roblox Society's highest role cannot be an unboxable role.

Server admins cannot make roles that're higher than there own unboxable. [?]

/role_collector unbox ✅ Active

Unbox a role in the server.

/unboxable_roles ✅ Active

View all of the unboxable roles in a server.

⁉️ Q&A

Frequently asked questions about Roblox Society

▶ How do I add Roblox Society to my server?

You can invite Roblox Society to your Discord server by clicking the invite link in our official Discord server or using the invite button on our website. You'll need "Manage Server" permissions to add the bot.

▶ Why are some commands disabled?

Some commands are temporarily disabled while we rebuild them with significant improvements. We prioritize quality over availability - these commands will return better than before! Check the Home page for detailed status on each disabled command.

▶ Is the bot free to use?

Yes! Most commands are completely free. Some advanced features like /rsgroup may have premium tiers in the future, but core functionality will always remain free.

▶ How do I report a bug or suggest a feature?

Join our official Discord server and use the bug report or suggestion channels. We actively review all feedback and appreciate community input for improvements!

▶ What's the difference between /rs and /asset content?

/asset content is our beta testing ground for new features. New capabilities are tested there first before being merged into the main /rs command once stable.

▶ Can I use the bot for my Roblox group?

Absolutely! Commands like /rsgroup, /group info, and /group members are specifically designed for group management and asset organization.

▶ How does Role Collector work?

Role Collector is a fun server game where members can "unbox" collectible roles. Server admins configure which roles are available and their rarity. Members use /role_collector unbox to try their luck!

▶ Where does the limited item data come from?

Limited item data including RAP and value estimates are sourced from Rolimon's, a trusted third-party Roblox economy tracking service.
